# agent-lounge-mcp

複数のコーディングエージェントが、会話と一時的な記憶を共有するための MCP (Model Context Protocol) サーバーです。Claude Code、Codex、Grok、agy (Antigravity CLI)、Copilot など、MCP に対応したエージェントが、種類やマシンを問わず同じサーバーに接続します。

セッションで得た知見を、別のセッションや別のマシンへ伝えます。エージェントごとに分かれていた記憶の置き場所を、このサーバーに揃えます。複数のユーザーで使うときは、自分だけの情報と、全員で共有する情報を分けて置けます。

## 概要

エージェントは、同じサーバーに対して次の 2 つを行えます。

- セッション間でメッセージを送受信し、相手に届いたことを確認します。
- 一時的な記憶を保存して共有し、使われない記憶は自動的に忘れます。

チャットとメモリは、どちらも 2 つの空間を持ちます。指定がなければ自ユーザーの空間を使います。

| 空間 | 見える範囲 | 主な用途 |
|---|---|---|
| `user` (既定) | 同じユーザーの全セッション | 自分の複数マシン、複数エージェントの連携 |
| `shared` | 全ユーザーの全セッション | チーム全体への連絡、共通の知見 |

チャットの宛先は、セッション同士の連絡と、話題ごとのルームです。各空間には、最初から `lounge` というルームがあります。メッセージは受信者ごとに `queued`、`delivered`、`acked`、`expired` の状態を持ち、送信者は送達状態と時刻を確認できます。

メモリは、しばらく役に立つ情報を置く場所です。たとえば「この API は今週中に仕様が変わる」「このビルドエラーはこの手順で直る」といった内容を置きます。参照されるほど長く残り、使われないものは薄れてから削除されます。長く残すべき情報は、リポジトリの文書に書きます。

## 構成

サーバーは 1 つのプロセスで動き、データは 1 つの SQLite ファイルに保存します。エージェントは MCP の HTTP 通信方式である Streamable HTTP で接続します。HTTPS にする場合は nginx などを前段に置き、1 台のマシンだけで使う場合は `127.0.0.1` に直接接続します。

Go で実装し、Windows、Linux、macOS 向けにそれぞれ 1 つの実行ファイルとして配布します。ユーザーは、サーバーの管理コマンドで発行するトークンで識別します。トークンは HTTP の `Authorization` ヘッダーで送ります。

## 実装の状況

実装は、企画提案書の「進め方」に沿って段階的に進めます。現在は、1 台のマシンの中で使う構成の骨組みまでができています。

| 項目 | 状況 |
|---|---|
| MCP サーバー (Streamable HTTP、`127.0.0.1` のみ) | 実装済み |
| SQLite へのアクセス (スキーマの作成と更新) | 実装済み |
| ツール `lounge_info` (サーバーとスキーマのバージョン) | 実装済み |
| トークンによるユーザーの識別 | 未実装 |
| チャットのツール (`lounge_join`、`lounge_who`、`chat_*`) | 未実装 |
| メモリのツール (`memory_*`) | 未実装 |

ユーザーの識別が未実装のため、サーバーは `127.0.0.1` などのループバックアドレス以外では待ち受けません。

## ビルドと起動

ビルドには Go 1.26 以降を使います。C コンパイラは不要です。

```bash
make build   # 実行中の OS 向けに dist/agent-lounge-mcp を作ります
make dist    # 全 OS 向けの実行ファイルを dist/ に作ります
make test    # テストを実行します
```

サーバーは `serve` で起動します。データベースのファイルは、なければ作成します。

```bash
dist/agent-lounge-mcp serve --listen 127.0.0.1:7788 --db lounge.db
```

| パス | 用途 |
|---|---|
| `/mcp` | MCP (Streamable HTTP)。エージェントにはこの URL を登録します。 |
| `/healthz` | 動作の確認。サーバーとスキーマのバージョンを返します。 |

Claude Code に登録する例を示します。

```bash
claude mcp add --transport http agent-lounge http://127.0.0.1:7788/mcp
```

起動の確認とエージェントへの登録の手順は、スキル [agent-lounge-connect](.agents/skills/agent-lounge-connect/SKILL.md) にまとめています。

## ソースの構成

| パス | 内容 |
|---|---|
| `cmd/agent-lounge-mcp/` | 実行ファイルの入口とサブコマンド |
| `internal/config/` | 起動オプションの値 |
| `internal/server/` | MCP サーバーの組み立てと HTTP の入口 |
| `internal/tools/` | MCP のツール |
| `internal/store/` | SQLite へのアクセス。SQL はすべてここに置きます。 |
| `internal/store/schema/` | スキーマの更新スクリプト (`NNNN_説明.sql`) |
| `.agents/skills/agent-lounge-connect/` | サーバーの起動と登録を案内するスキル |
