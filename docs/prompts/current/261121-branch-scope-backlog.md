## BL-004 `shared` の空間と `scope` 引数

## BL-042 Windows の Codex で、出力の途中に作業中の表示が画面にない

### 概要と問題点

- **継続作業での経緯と対処**: 案件 `expiry-sandbox-verification` で追加しました (2026-11-20)。 `261120-expiry-sandbox-verification-backlog.md` の同じ課題 ID から、案件 `branch-scope` の残課題一覧 (この文書) へ転記しました (2026-11-21)。
