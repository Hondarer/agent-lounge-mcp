## LADR-002 origin の相対パスの扱い

決定者: Tetsuo Honda  
最終更新日: 2026-11-20

### 背景と課題

origin の正規化は、正規化済みの形 (`ホスト/パス`) を受け付けます。Git は相対パスの origin (例: `foo/bar`) を許すため、今の規則では、手元のフォルダーを指す origin が、ホスト `foo` の単位として読まれます。

### 得られた事実

- `git remote get-url origin` の出力は、URL の形か `ユーザー@ホスト:パス` の形で、正規化済みの形にはなりません。正規化済みの形は、エージェントが単位の値を写して渡す場合に備えたものです。

### 決定

正規化済みの形は、ホストの部分が `.` を含むか `localhost` のときだけ受け付けます。それ以外の、方式もコロンもない値は、ローカルの相対パスとして origin なしにします。

## LADR-004 検証の基盤で直す範囲

決定者: Tetsuo Honda  
最終更新日: 2026-11-20

### 背景と課題

検証の基盤の残り (BL-035) の 11 の番号のうち、この案件で直すものと、直し方を決める必要がありました。

### 得られた事実

- 一時フォルダーで、5 つの CLI (WSL の側) を調べました。入力欄は、5 つとも Ctrl+U で消せます。
- 許可のオプションなしで許可の画面が出たのは、Copilot CLI だけです (「Do you want to use this tool?」と「Do you want to run this command?」。Enter で許可)。
- 入力を待つ表示は、Codex と Grok では作業中も出たままです。作業中だけ出る表示は、5 つともあります (Claude Code と Codex は `esc to interrupt`、Copilot CLI は `ctrl+c interrupt`、Grok は `Ctrl+c:cancel`、agy は `esc to cancel`)。
- 手元に残っていた古い Copilot CLI と agy のプロセスは、利用者が別のリポジトリで動かしているもので、基盤が残したものではありません。

### 決定

(1)、(2)、(4)、(5)、(6)、(8) を直し、(11) を記録して除きます。(1) は、定義に許可の画面の文字列と応答のキーを加える仕組みを入れ、Copilot CLI はシェルの一括の許可をやめて、シェルのコマンドの画面に Yes で応答し、回数を結果に記録します。他の 4 つの CLI の許可の画面は、残課題に残します。(6) は、完了の語の後に 4[秒] 出力がなく、かつ、作業中の表示が画面にないときに、完了とします。(3)、(7)、(9)、(10) は、残課題に残します。

## LADR-005 無効になったトークンの待ち受け

決定者: Tetsuo Honda  
最終更新日: 2026-11-20

### 背景と課題

待ち受け中の `chat_inbox` は、その間にトークンが無効になっても気付かず、新着を 1 回受け取れます (BL-032 の 1 番)。管理コマンドは別のプロセスで、サーバーに知らせる手段がありません。

### 得られた事実

- サーバーは、HTTP の要求のたびにトークンを確かめます。待ち受けは、1 つの要求の中で、最長で待ち受けの上限 (既定は 45[秒]) まで続きます。

### 決定

待ち受け中、5[秒] ごとと、新着で起きたときに、要求のトークンがまだ有効かを確かめます。無効なら、待ち受けをやめ、メッセージを渡さずにエラーを返します。

## LADR-007 確認の範囲

決定者: Tetsuo Honda  
最終更新日: 2026-11-20

### 背景と課題

変更を、どの OS で、実機の CLI を使ってどこまで確かめるかを決める必要がありました。

### 得られた事実

- サーバーの変更は、OS によって変わる部分を含みません。
