## 最終仕様との相違

- **`/` を含まない origin (2.1)**: 最終仕様の規則では、`.` を含む値 (`repo.git`、`my.app`) はホストとして読まれ、パスがないエラーになります。実装では、方式も `:` も `@` も `/` もない値を、すべて origin なしにしました。`/` がなければ `ホスト/パス` の形になり得ず、`repo.git` は相対パスの origin として最もありそうな形のためです (レビューの指摘 5)。
- **許可の画面の見分け方 (6.1)**: 最終仕様は「応答の後は、その時点より後の出力だけを調べる」としていました。実装では、質問の行の上の 8 行が、応答した画面と異なるときに、新しい画面と数えます。同じ内容の画面には、15[秒] たってから、もう一度応答します。Copilot CLI が、続けて出す画面の質問の行を書き直さないためです (実機で判明)。
- **ツールの説明文 (第 1 章の対象外)**: `lounge_who` の出力の `last_seen_at` の説明 (`internal/tools/lounge.go`) を、「最後にツールが成功した時刻」から「参加済みの接続が、最後にツールを呼んだ時刻」に改めました。第 5 章の変更で、元の説明が誤りになるためです。`lounge_help` の案内は変えていません。
- **`SessionExists` (5.2)**: 製品のコードから削除し、テストの補助の関数 (`internal/store/chat_test.go` の `sessionExists`) に置き換えました。
- **実機での確認の回数 (6.8)**: 途中のコードで問題が見つかったため、WSL の側は 3 回、Windows の側は Copilot CLI を 3 回、他の 4 つの CLI を 2 回、実行しました。Windows の側の他の 4 つの CLI は、最終のコードでは実行していません (最終の変更が、許可の画面を定義した CLI だけに関わるため)。
