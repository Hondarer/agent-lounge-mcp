### Q-004 shared を使えるユーザー

**Status**

解決済み

**Question**

`shared` のスコープを、どのユーザーが使えるようにしますか。

**Context**

- **経緯と背景**: 企画提案書の「空間の分け方」は、`shared` を「全ユーザーの全セッション」が読み書きできる空間とし、使える条件を定めていません。トークンに権限の区分はありません (BL-031 の (2))。
- **今の利用者から見た変化**: 今は、他のユーザーのセッションが見えるのは、同じリポジトリの単位 (またはブランチ) を申告している場合だけです (`docs/ja/reference.md` の「スコープ」)。`shared` を全ユーザーに開くと、サーバーを新しい版にしただけで、すべてのユーザーのセッションが互いに届く相手になります (一覧に載るかは [Q-005](#q-005-lounge_who-の一覧の範囲) で確認します)。
- **固定のユーザー `local`**: ループバックだけで待ち受けるサーバーは、トークンのない接続を `local` として受け付けます。`local` だけで使う場合、`shared` は `user` と同じ相手になります。
- **各案の具体例**:

```text
案 A: 常に使える
  alice のセッション → chat_send(scope: "shared", to: "bob/claude") → 届く (bob と同じリポジトリでなくても)

案 B: 起動オプションで有効にする (既定は無効)
  agent-lounge-mcp serve --enable-shared ...   ← 付けたサーバーだけで使える
  付けていないサーバー → chat_send(scope: "shared", ...) → エラー (このサーバーでは shared を使えない)

案 C: 管理者がユーザーごとに許可する
  agent-lounge-mcp user shared alice --allow   ← 許可したユーザーだけが使え、許可したユーザーの間でだけ届く
```

**Answer**

選択方式: 単一選択

- [x] A: すべてのユーザーが常に使える (企画提案書のとおり)。
- [ ] B: (推奨) サーバーの起動オプションで有効にした場合だけ、すべてのユーザーが使える (既定は無効)。
- [ ] C: 管理者がユーザーごとに許可したユーザーだけが使える。
- [ ] D: その他
- [ ] X: 意図不明 (詳細な質問内容に再生成すること)

### Q-005 lounge_who の一覧の範囲

**Status**

解決済み

**Question**

`shared` を使えるセッションの `lounge_who` に、`shared` だけを共有する他のユーザーのセッション (同じリポジトリの単位でない、他のユーザーのセッション) を載せますか。

**Context**

- **経緯と背景**: `lounge_who` は、呼び出し元が「どれかのスコープで届く相手」を、引数なしで 1 回ですべて返します (`docs/ja/reference.md` の「lounge_who」)。実装は、呼び出し元が使えるスコープの範囲の和を一覧します (`internal/store/chat.go` の `VisibleSessions` が `ScopesOf` の各スコープの条件を `OR` でつなぐ)。`shared` の規則を足すと、何もしなければ、全ユーザーの全セッションが一覧に入ります。
- **上限**: 一覧は、最終利用時刻の新しい順に 200 件までです。ユーザーが多いと、自分のユーザーや同じリポジトリの相手が、200 件の外に押し出される場合があります。
- **企画提案書**: 「相手の一覧では、セッションごとに、共有しているスコープと識別子を示します」とあり、一覧の範囲は「届く相手」です。
- **各案の具体例** (`alice` から見た一覧):

```text
案 A: すべて載せる
  sessions: [ {address: "claude", scopes: [user, shared]},
              {address: "bob/codex", scopes: [repository, shared]},
              {address: "carol/grok", scopes: [shared]}, ... ]   ← 全ユーザー、200 件まで

案 B: 既定では載せず、引数で求めたときだけ載せる
  lounge_who()                → carol/grok は載らない (今と同じ範囲)。scopes には shared が付く
  lounge_who(scope: "shared") → shared の範囲 (全ユーザー) を一覧する

案 C: 載せない (宛先は利用者が user/name で直接指定する)
  lounge_who() → carol/grok は載らない。chat_send(scope: "shared", to: "carol/grok") は届く
```

**Answer**

選択方式: 単一選択

- [x] A: 載せる。`lounge_who` は、`shared` を含む、届くすべての相手を返す。
- [ ] B: (推奨) 既定では載せない。`lounge_who` に範囲を選ぶ引数を足し、`shared` を指定したときだけ載せる。
- [ ] C: 載せない。`shared` だけで届く相手は、利用者が宛先を直接指定する。
- [ ] D: その他
- [ ] X: 意図不明 (詳細な質問内容に再生成すること)
