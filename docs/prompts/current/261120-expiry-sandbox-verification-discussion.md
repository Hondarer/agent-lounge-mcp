### Q-004 WSL から Windows の側のサーバーへの接続

**Status**

解決済み

**Question**

Windows の側で起動したサーバーに WSL の側から接続する確認 (項目 c) を、どう扱いますか。

**Context**

Windows の側のセッションに、読み取りだけで調べてもらいました。

- WSL のネットワークは、既定の NAT のモードです (`.wslconfig` に `networkingMode` の指定がない)。WSL からは、Windows の側のアドレス (WSL の既定のゲートウェイ) に接続します。サーバーは、`--allow-remote --listen 0.0.0.0:<ポート>` で起動し、トークンが必須になります。
- Windows のファイアウォールは有効で、新しい実行ファイルがループバック以外で待ち受けると、受信の許可を求める画面が出る見込みです。`dist` の実行ファイルの受信の規則は、まだありません。

このため、項目 c は、利用者がファイアウォールの画面で許可する (または、受信の規則を足す) 必要があります。許可した規則は、利用者のマシンに残ります。

**Answer**

選択方式: 単一選択

- [x] A: (推奨) 確かめる。受信の許可を求める画面が出たら、利用者が「プライベート」で許可する。確認の後、規則を消すかどうかは、利用者が決める
- [ ] B: 確かめる。Windows の側のセッションが、確認用の受信の規則を足し、確認の後に消す (管理者の権限が必要)
- [ ] C: 確かめない (項目 c は未検証のまま残す)
- [ ] D: その他
- [ ] X: 意図不明 (詳細な質問内容に再生成すること)
