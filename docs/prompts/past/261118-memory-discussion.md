| 事項 | 判断 | 理由 |
| --- | --- | --- |
| サーバーの起動の順 | 上限と忘却の設定を適用してから、定期の処理を始める | 定期の処理が忘却の設定を読むため、適用の前に始めると、値の読み書きが同時に起きる |
| 3 文字未満の語の大文字と小文字 | すべての文字を小文字にする SQL の関数 (`fold_case`) を登録して比べる | SQLite の `lower()` は ASCII だけを変換し、索引 (trigram) の動作と食い違う (レビューの指摘) |
| 保持スコアの表示 | 小数第 3 位以下を切り捨てる (100 万分の 1 の許容つき) | 薄れたメモリが、しきい値と同じ値で表示されないようにする (レビューの指摘) |
| 忘却の期間の計算 | 期間の上限で止める | 大きな設定値で計算があふれ、メモリがすぐに薄れる (レビューの指摘) |
| Codex の承認 | ツールの注記を変えず、Codex の設定 (`default_tools_approval_mode`) を利用ガイドとスキルに書く | `memory_put` と `memory_forget` は実際にデータを書き換えることがあり、注記はその動作に合っている |
| 確認用のスクリプト | `chat-probe.sh` に、リポジトリのスコープのメモリの保存、検索、取得、削除の確認を加える | 確認の後にデータを残さない形で、メモリの共有を確かめられる |

### 調査で確認した事実

ユーザーが明示した内容は、次のとおりです (対話での指示)。

- 前の案件の成果物を承認し、`main` にマージしました。次の案件を開始します。

- 残課題は、その都度、全量を引き継ぎます (以前の案件での指示)。
- 確認用のデータベースは、`dist/` に置きません (前の案件の後の指摘)。

企画提案書で確認したことは、次のとおりです。

- メモリは、一時的な記憶を共有する場所で、長期の知識ベースにはしません。意味の近さで探す検索 (ベクトル検索) は、範囲に含めません。
- 1 件のメモリは、本文、任意の題名、タグ、空間、作成時刻、更新時刻、最終参照時刻、参照回数、固定の有無を持ちます。
- 忘却モデルは、参照頻度と、作成または更新の時刻から決まります (要件)。計算式は、「基準時刻 = 更新時刻と最終参照時刻の新しいほう」「半減期 = 基本半減期 × (1 + log2(1 + 参照回数))」「保持スコア = 2 ^ (-(現在時刻 - 基準時刻) / 半減期)」です (提案)。
- 保持スコアがしきい値を下回ると、薄れた状態 (通常の検索に出ない。ID の指定で取得でき、取得すると戻る) になり、猶予期間の後に削除されます。固定したメモリは、忘却の対象から外れます。保持スコアは検索や取得のときに計算し、削除はサーバーの定期の処理が行います。
- ツールは、`memory_put`、`memory_search`、`memory_get`、`memory_pin`、`memory_forget` の 5 つです。
- 検索は、FTS5 の trigram を使います (提案)。
- メッセージとメモリは、送信者 (作成者) と空間を明示して返します。秘密情報と個人データを書き込まないことを、ツールの説明文に明記します。
- 未確定の事項は、「メモリでのリポジトリの空間」と「参照回数の数え方」です。
- 完了の目安は、「薄れる動作と削除を、時刻を進めた試験で確認できます」です。

現在の実装で確認したことは、次のとおりです。

- スコープは、種類 (`user`、`repository`) と識別子の組です (`internal/store/scope.go`)。`shared` は、未実装です (BL-004)。
- 定期の処理 (起動時と、`--cleanup-interval` ごと) があり、期限切れ、メッセージの削除、セッションの削除を行います。時刻は、試験で差し替えられます (`SetClock`)。期間の起動オプションは、`d` (日) の単位を受け付けます。
- すべてのツールの応答に、未読の件数を付記します。`lounge_who` と `chat_*` は、参加を必要とします。
- `chat_history` は、`scope` を省くと、使えるすべての空間のやりとりを返します。
- 書き出し (`export`) は、チャットだけを書き出します。ファイル名の規則は、`internal/export/` にあります。
- FTS5 の trigram が使えることは、自動テスト (`TestFTS5TrigramIsAvailable`) で確認済みです。
- trigram の索引は、3 文字未満の語では一致しません (この案件の調査で、SQLite 3.54.1 で確認。[Q-012](#q-012-3-文字未満の検索語の扱い))。

未確認のことは、次のとおりです。
